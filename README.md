# デリ勘（UbeROI）

全国どこでも、自転車（シェアサイクル・自前の電動アシストなど）でフードデリバリーの副業をする人のための、収益計算アプリ（スマホ向けPWA）。
家を出てから帰るまでの時間・シェアサイクル代・装備や車両への投資まで含めて、本当の時給と投資の回収具合を出します。

- いまの状態：**v0.1（MVP）完成**。記録（出発・レンタル・帰宅精算）、続けるか帰るか、クエスト、計画、分析、装備と投資、バックアップと復元、CSVの取り込みが使えます。受入基準の確認結果は下の「受入基準の確認」。進み具合は `docs/CURRENT_TASK.md`

## スマホで使う

1. スマホのブラウザーで https://165cm.github.io/UbeROI/ を開く
2. ホーム画面に追加する（iPhone：Safari の共有ボタン →「ホーム画面に追加」／Android：Chrome の「︙」→「ホーム画面に追加」）
3. 一度開けば、電波がない場所でも開いて記録できます。新しい版が出ると「更新する」ボタンが出ます

## データの保存とバックアップ

- 記録はスマホのブラウザーの中（IndexedDB）にだけ保存されます。外部には送りません（暗号化はしていません）
- エリアの地図を開いた時だけ、OpenStreetMap から地図の画像を読み込みます（見ている辺りの地図の位置だけが伝わり、記録や現在地は送りません）
- ブラウザーのデータ削除や機種変更で消えるので、ときどき「設定 → データ → バックアップを書き出す」で保存し、クラウドやパソコンにも残してください（確定した記録があり、7日以上書き出していないとホームでお知らせします）
- 戻す時は「設定 → データ → バックアップから復元」でファイルを選びます。中身（件数）を確かめてから、今のデータを**すべて置き換え**ます。版が違う・壊れているファイルは読み込まず、今のデータはそのまま残ります
