# 01 製品仕様
## 1. ユーザーと目的
主利用者は限られた週の空き時間で配達する1人の副業ユーザー。起点の表示名は「千歳烏山駅周辺」。自宅の正確な住所は初期入力に要求しない。
「今から働くか」「どこから借りるか」「何時間働くか」「いつ帰るか」に答える。主KPIは出発から帰宅までを分母とする税引前の営業純時給。投資配賦後時給と投資回収状況を併記する。

## 2. MVP境界
|優先度|内容|完成時の動作|
|---|---|---|
|P0|初期設定|起点、目標時給、週の上限時間、車種、料金、装備登録|
|P0|稼働記録|出発・帰宅、オンライン区間、レンタル区間、件数、売上、経費|
|P0|収益エンジン|営業利益、実質時給、投資配賦、回収残額、段階料金|
|P0|装備設定|初級・中級・上級の比較、価格編集、所有済み・予定・購入済み|
|P0|分析|日週月の売上/費用/利益、時給、投資回収曲線|
|P0|保存と復元|端末保存、JSONバックアップ、検証付き復元、CSV出力|
|P1|計画|週の候補時間枠と手入力の売上見込みによる比較|
|P1|ルール助言|GO/WAIT/STOP、根拠とデータ不足状態|
|P1|独自CSV取込|プレビュー、列検証、重複防止、一括確定|

## 3. ナビゲーションと画面仕様
モバイル下部に「ホーム / 記録 / 分析 / 計画 / 設定」。補助画面は戻るで復帰。幅390pxを基準とし320〜1440pxで崩れない。色だけで利益/損失や判定を伝えない。タップ領域44px以上、文字拡大200%、キーボードとスクリーンリーダーに対応。

### S01 初期設定
起点名（初期値: 千歳烏山駅周辺）、目標純時給（円/時）、週の利用可能時間、帰宅締切、車種、料金を入力。料金は出典・確認日を表示し編集可能。装備プリセット選択は任意。完了するとホーム。値未入力は「未設定」とし0円で穴埋めしない。

### S02 ホーム
上段: 今日の状態（未開始/稼働中/帰宅未記録/確定）。主カード: 営業純利益・営業純時給、隣に投資配賦後時給。実績がなければ予測モードを明記。
中段: HELLO開始からの経過時間、見積料金、次の課金までの残り時間、返却予定。料金確定前は「見積」。
下段: GO/WAIT/STOPと理由、入力品質、帰宅締切。開始/記録/終了ボタン。自宅出発とレンタル開始を別操作にする。復帰時は保存した開始日時から経過時間を再計算する。

### S03 稼働記録・終了精算
簡易モードは日次の集計入力。任意で配達ごとの詳細モードを使う。売上=基本報酬+チップ+確定ボーナス+調整。レンタル実請求額・その他費用を入力。オンライン時間と自宅往復時間を混同しない。保存前に計算明細を提示。帰宅未入力は下書きで保存し確定集計から除く。
過去記録を編集/削除可能。削除は確認と直後の取り消しを用意する。詳細モード移行時は集計入力との差を表示してどちらを採用するか選ぶ。

### S04 分析
期間選択（日/週/月/任意）と税込実支払額ベース・税引前表示。売上→レンタル→経費→営業利益→投資配賦後利益のウォーターフォール相当の表とグラフ。現金回収曲線は別図。平均時給は総利益÷総拘束時間。欠損除外件数を表示。曜日/時間/エリア分析は件数と標本数を表示し少数標本を強調しない。CSV出力。

### S05 計画・比較
利用可能枠、開始時刻、帰宅期限、予想売上/件数、想定レンタル、経費を入力。悲観/標準/楽観の3シナリオを横比較。初級/中級/上級の変更は投資回収見通しに反映し、価格だけから売上増加を仮定しない。週上限は帰宅までの合計時間を使う。

### S06 設定・初期投資（重点画面）
上部: 初級/中級/上級のセグメントとセット総額、今回必要な現金、所有済み資産額。各レベルは代替案であり全レベルを合算しない。
明細カード: 品目・分類・価格（税込円）・数量・購入日・利用開始日・状態（予定/購入済み/所有済み）・業務使用割合・配賦期間（月）・想定残存額。価格未確認は空欄。所有済みの今回支出は0円、管理用価値は任意。
「プリセットをコピー」「明細追加」「保存」「変更取り消し」。プリセット再適用は既存購入を上書きせずプランにコピー。保存直後、分析の回収残額と配賦後時給を更新する。

提案プリセット（安全装備を上位専用にしない）:
- 初級: 保温配達バッグ、適合するヘルメット、固定具、モバイル電源、雨具、視認性補助用品。
- 中級: 初級と同じカテゴリの耐久・防水性能を選ぶ、予備ケーブル/電源を任意追加。
- 上級: 同じカテゴリの長時間運用向け品、予備バッグ等を任意追加。
装備価格はユーザー入力。fixturesの価格は市場相場ではない。通信/保険など継続費用は別タブで登録。

### S07 データ管理
最終バックアップ日時、JSON書き出し/復元、CSV取込、デモ切替、全削除。復元はスキーマ確認→件数/重複/エラー表示→明示確定。失敗時に元データを維持。

### S08 ポート・エリア（P2）
取得できたポートだけを表示。位置情報拒否時は起点から検索。空き台数/返却枠の観測時刻と古さを表示。欠損を0台に置換しない。公式アプリで返却可能か確認できる導線。予測需要と実測ポート状況は別レイヤーにする。

## 4. 状態と入力品質
読み込み/空/成功/エラー/オフライン/古い外部データの状態を各画面に用意する。フォーム変更中の離脱を保護。金額0は有効、負の調整は調整明細だけ許可。確定済みセッションの料金プランはスナップショットで保持する。
