# Claude Code への実装指示
このディレクトリの仕様からUbaROI v0.1を実装する。最初に全docsとfixturesを読み、既存リポジトリがあれば既存の構成・指示を優先して整合させる。

## 優先順位
計算の正確性 → データ保存・復元 → モバイル入力 → 分析 → 予測説明 → 外部連携。
原案はSheetsからの検証を推奨していたが、この引き継ぎではユーザーのアプリ制作依頼に合わせ、ローカルファーストPWAをMVPとして提案する。外部APIなしで使えること。

## 実装上の約束
- docs/02-profitability.mdを計算の正本とし、画面やLLM内に別の計算式を実装しない。
- 税引前・予測/確定・現金/配賦・サンプル/実績を区別する。
- UI画像が未取得でも画面仕様から進める。未取得画像を再現済みと報告しない。
- 初期投資の購入額と配賦額を同じ利益から二重控除しない。
- UberやHELLOの非公開API・自動操作に依存しない。MVPは手入力と自社CSV形式。
- 桁あふれ、不正日時、欠損、二重取り込み、0除算を先にテストする。
- サンプルデータは独立したデモモードに置き、実績へ混ぜない。
- ブラウザーだけでAPI秘密鍵を保存・配信しない。
