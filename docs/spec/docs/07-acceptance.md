## 最低限のE2E
初期設定→装備購入→出発→レンタル→帰宅精算→分析→記録訂正→バックアップ→復元を1本のシナリオで検証。期待値はfixturesと照合。これとは別にデータ消失・二重取込・外部障害を確認する。
