# UI刷新（2026-10-07）

ユーザー承認済みのレビュー・画像案を、次の3段階で実装する。計算式と保存形式は維持する。

1. 初期設定・週間計画：週の時間が未設定なら自動の作戦を出さず、料金・目標時給・働ける時間を設定する。登録済み候補から選ばれた枠と、まだ登録していない提案を明記する。既存の候補選択は最適化によるもので、ユーザーが確定した予定と呼ばない。
2. 画面構成：今日／計画／記録／分析を下部に置き、設定はヘッダーへ。稼働操作を優先し、判断支援の入口をまとめる。精算は時間の要約と任意入力を整理し、分析は空状態から記録を案内する。
3. 見た目：昼はオフホワイトと深緑、夜は暗い緑とミント。数字・余白・操作サイズを拡大し、主要ナビゲーションの線画アイコンを統一する。

## 計画の状態

- 週の時間が null：未設定。自動の作戦は計算・表示しない。手動で候補を追加できる。
- 週0時間：今週は働かない。未設定に戻さない。
- 既存利用者が週の時間だけ設定済み：これまでの提案を維持し、未設定の条件と既定の扱いを画面に明示する。
- 未登録の提案：登録済みの集計には含めない。「この提案を候補に追加」で既存の保存処理へ渡す。候補に追加後も最適化で採否が決まるため、必ず採用されるとは表現しない。
- 推計の元データが少ない場合、参考値であることを常時表示する。天気・クエスト・料金の詳細は既存の説明と明細を保つ。

## 検証

各段階で型検査・単体テスト・ビルドと関連E2Eを実施。最終段階で全E2E・アクセシビリティ、320/390px・横画面・デスクトップを確認する。古いiPhoneの構文互換テストを維持する。本番公開はPRごとのユーザー承認後。
