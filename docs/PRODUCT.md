# 何を作っているか（PRODUCT）

## ひとことで

千歳烏山駅周辺から自転車（シェアサイクルや自前の電動アシスト）で Uber Eats などの配達をする副業の人が、**家を出てから帰るまでの時間と、装備・車両への投資を含めて「本当に儲かっているか」を判断する**スマホアプリ「デリ勘」。

答えたい問い：今から働くか／どこから借りるか（買うべきか）／何時間働くか／いつ帰るか。

## 中心の使い方

設定する → 出発・レンタル開始 → 帰宅して精算を記録 → 分析で時給と投資回収を見る → 次の週の計画を立てる

- 主な指標：出発から帰宅までを分母にした税引前の営業純時給
- 一緒に出すもの：投資配賦後の時給、投資回収の残額

## 強み

- シェアサイクルの段階料金を秒単位で正確に計算し、「次にいつ料金が上がるか」が分かる
- 装備・車両の初級／中級／上級を比べて、回収の見通しに反映できる
- サーバーなし・端末内保存なので、外部APIなしでオフラインでも使える
- 仕様の詳細は `docs/spec/docs/01-product-spec.md`、追加の決めごとは `docs/CURRENT_TASK.md`

## やらないこと（追いかけない）

- 注文の自動受諾、走行中の画面解析、配達アプリの自動操作
- Uber や HELLO CYCLING の非公開APIへの依存
- 税の申告、保険が業務に使えるかの判定
- 公式サービスとの提携に見える表示
- 複数人での利用・クラウド同期
