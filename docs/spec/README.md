# UbaROI — Claude Code 実装引き継ぎパッケージ
作成日: 2026-10-05 / 仕様版: 0.1 / 言語: 日本語

## 目的
千歳烏山駅周辺を起点に、HELLO CYCLINGでUber Eats配達をする副業ユーザーが、帰宅までの時間と初期投資を含めて収益を判断するスマートフォン向けアプリ。

## 最初に読む順序
1. CLAUDE.md — 実装開始指示と優先順位
2. docs/01-product-spec.md — 要件・MVP・画面
3. docs/02-profitability.md — 計算の唯一の正本
4. docs/03-data-model.md — エンティティ・制約
5. docs/04-architecture.md — 技術構成・API・非機能
6. docs/05-ai.md — AI機能と段階的導入
7. docs/06-implementation-plan.md — 実装手順
8. docs/07-acceptance.md — 受入基準
9. docs/08-sources-and-decisions.md — 出典・不足・仮定
10. assets/ui/README.md — 画像取得結果と画面仕様の対応

## 引き継ぎ上の重要事項
参照会話の取得可能な全4ターンを確認した。初回の提案文とユーザーの追加要求は取得できたが、後続のUI生成への回答と画像添付は取得結果に含まれていない（attachments=[]）。したがって同梱された過去UI画像は0点。画像を創作して過去の成果物と偽装していない。取得不能と画像未生成は同義ではない。

本仕様は取得できた構想と追加要求をもとに、実装可能な決定事項を補った引き継ぎ案。補完した技術選定・画面構成・装備価格は過去に合意済みの事実ではない。実配達実績、需要、店舗待ち時間、ポート空き状況の実測データは含まない。fixturesは明示的な合成テストデータ。

MarkdownとJSONのため専用アプリ不要。ZIP内のMANIFEST.sha256でファイル整合性を検証できる。パッケージは実装ソースや完成アプリではない。
