# 自転車でのフードデリバリー副業：収益性の参考資料（全国版・2026年10月）

デリ勘の計画画面の初期値や助言の根拠に使う、地域を問わない参考情報です。2026年10月時点の公開情報（配達員ブログ・調査・公式発表）をまとめたもので、**実績ではありません**。時給の数値は他人の実録や全国調査からの目安・推計で、実際は地域の注文密度・配達員の多さ・クエストの配信状況で大きく変わります。数値はアプリと公式サイトの最新表示で確かめてください。

## 1. Uber Eats の報酬のしくみ（2026年）

- 報酬は「予定配送料＋クエスト＋チップ」。サービス手数料10%は2022年8月、配達調整金は2025年12月16日に廃止され、オファー画面の金額がほぼそのまま報酬になる（デリナビ、noshift）
- 予定配送料は予定時間・ピックアップ/ドロップ数・交通・店舗待ち・注文量・稼働中の配達員数などから動的に決まる。内訳と最低額は非公開。自転車の最低は約320円という観察がある
- **選択制クエスト**：2026年1月16日から全国で選択制。10〜120回の12段階から選び、**月曜4:00〜金曜4:00**と**金曜4:00〜月曜4:00**の二部制。2026年は単価が下がったとの報告が複数ある
- **ピークタイムクエスト**：ランチ（10:30〜15:00）とディナー（17:00〜21:30）。出る日・出ない日の差が大きい
- **悪天候クエスト（雨クエ）**：雨・雪の日に12回までの段階報酬。例：12回で合計1,200〜1,800円。人・エリアで金額が違ったり出なかったりする
- **連続稼働インセンティブ**：2026年2月16日に全国導入
- **クエストの比重**：都心の自転車配達員の長期記録では、収入の約20%がクエスト等の特別報酬（2025年は21.41%）。クエスト込みと抜きで時給が約2〜3割違う
- **Uber Eats Pro 新ランク**（2026年7月1日〜）：応答率・キャンセル率が条件に加わり、月の途中でもランクが上下する。目安はゴールド（応答率20%以上・キャンセル率10%以下・60pt）、プラチナ（30%以上・8%以下・300pt）、ダイヤモンド（30%以上・8%以下・550pt）
- **運転時間の上限12時間**：2026年5月11日の週から、オンライン中の移動時間も含まれる（止まって待つ時間は含まれない）

## 4. 車両の費用

- **シェアサイクルは事業者・地域で料金が違う**。例：
  - HELLO CYCLING（東京都シティサイクル）：最初の30分160円、以後15分160円、12時間まで上限2,500円
  - ドコモ・バイクシェア → NOLL（2026年9月〜）：10分99〜120円、時間パス3時間900円・6時間1,500円・12時間2,500円。月額3,300円プランは「30分以内・月30回まで」で配達向きではない
- **配達用サブスク**：例 NORUDE 月額4,960円〜（出張修理込み6,960円〜）
- **購入**：維持費は月1,500〜3,000円程度（充電・消耗品・バッテリー交換の積立。バッテリー寿命2〜4年、交換3万〜6万円）
- **判断の目安**：シェアサイクルを毎日数時間使うと1日1,500〜2,500円かかり、ピーク時給の約1時間分。週3日以上なら購入かサブスクが有利になりやすい。デリ勘では自分の稼働ペースで「何か月で購入が得になるか」を計算する

## 5. 掛け持ち・競合（2026年10月時点）

- Wolt は2026年3月4日に日本でのサービスを終了。menu は2026年9月30日でサービスを終了
- 掛け持ち先は実質「Uber Eats・出前館・ロケットナウ」。対応エリアは各公式で確認する
- 出前館は1件600〜800円程度が相場とされる。ロケットナウの上乗せリワードは件数条件（東京では週30件以上など）があり、自転車では難しいとの評価がある

## 6. 法規制・安全・税

- 2026年4月1日から自転車にも青切符（16歳以上、113種類）。反則金の例：ながらスマホ12,000円、信号無視6,000円、一時不停止5,000円、夜間無灯火3,000円
- 雨の日は白線・マンホール・金属の溝蓋でのスリップに注意
- 自転車保険（個人賠償責任）に入る
- 給与所得者の副業は、配達の所得（売上−経費）が年20万円を超えると確定申告が必要。経費にできるもの：車両の購入・レンタル費、修理代、スマホ代（業務分）、配達バッグ、雨具など。個別の判断は税務署・税理士へ

## 7. 稼ぎ方の一般則

1. ランチとディナーのピークに集中し、14〜17時は休む（シェアサイクルは返却して節約）
2. 雨の日・年末年始・夏に厚く稼働し、台風・雪の日は休む
3. 選択制クエストは2段目まで確実に取れる回数を選ぶ（副業なら30〜40回程度が目安）
4. 応答率・キャンセル率がランク条件を下回らないようにする
5. 店舗が集まる場所を待機の軸にし、帰り方向から外れる遠距離配達は高単価の時だけ受ける
