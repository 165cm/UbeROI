## 大事な決めごと

- 2026-10-05 GO/WAIT/STOP の判定：締切超え → STOP。必要な値の不足（目標未設定・料金対象外・見込み未入力・延長0分）→ WAIT。楽観でも目標未満 → STOP、悲観でも目標以上 → GO、その間 → WAIT。増えるレンタル代は「延長して返す時点の料金 − 今やめて返す時点の料金」（仕様 §5）
- 2026-10-04 計画の悲観／楽観は標準の売上の 0.8倍／1.2倍の手動の幅（統計的な信頼区間とは呼ばない。仕様 05）
- 2026-10-04 参考資料の推計の基準は 1時間 1,400円（全国の自転車の調査の目安）× 時間帯の倍率 × 月の倍率。本人の実績が10回以上になったら本人の平均に切り替える
- 2026-10-04 データの版を2に上げ、計画の候補枠（`slots`）を追加。版1のバックアップは候補枠を空として読み込む
- 2026-10-04 Service Worker は手書き（`sw/sw.template.js`）。ビルド時に全ファイルの一覧と中身から計算した版を埋め込む（`vite.config.ts`）。追加の部品（workbox 等）は使わない
- 2026-10-04 新しい版への切り替えは自動でしない（入力中のフォームを消さないため。仕様 04）
- 2026-10-04 復元は「全体の置き換え」のみ（マージしない。仕様 03）。今表示中（実績／デモ）の保存場所に入れる
