# デリ勘（UbeROI）

千歳烏山駅周辺から自転車でフードデリバリーの副業をする人のための、収益計算アプリ（スマホ向けPWA）。
家を出てから帰るまでの時間・シェアサイクル代・装備や車両への投資まで含めて、本当の時給と投資の回収具合を出します。

- いまの状態：実装前（仕様確定）。進み具合は `docs/CURRENT_TASK.md`
- 何を作っているか：`docs/PRODUCT.md`
- 開発のルール：`AGENTS.md` → `docs/DEVELOPMENT.md`
- 引き継ぎ仕様書の原本：`docs/spec/`

起動方法・バックアップ方法は、アプリを作った時にここへ書きます。

開発ルールは [165cm/ai-dev-template](https://github.com/165cm/ai-dev-template) のひな形に沿っています。
